## 1. คำสั่งเริ่มระบบ (PowerShell ที่โฟลเดอร์โปรเจกต์)
```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_demo_windows.ps1 -Reset
```
* `-Reset` = เริ่มฐานข้อมูลสาธิตใหม่ (ล้างรายงาน/override เก่า) — **ปลอดภัย: สคริปต์จะปฏิเสธเองถ้ามีเซิร์ฟเวอร์อื่นยังเปิดอยู่**
* ไม่ใส่ `-Reset` = ใช้สถานะเดิมต่อ
* ตัวเลือก: `-Port 8010` (เปลี่ยนพอร์ต), `-NoBrowser` (ไม่เปิดเบราว์เซอร์อัตโนมัติ)
* **อย่าปิดหน้าต่าง PowerShell นี้** ระหว่างนำเสนอ (ปิด = เซิร์ฟเวอร์ดับ)

## 5. แก้ปัญหาเฉพาะหน้า (ทุกข้อทดสอบจริงแล้ว ยกเว้นที่ระบุ)
| อาการ | สาเหตุ | ทำอย่างไร |

| สคริปต์ขึ้น `ERROR: port 8000 is already in use` | มีเซิร์ฟเวอร์เปิดอยู่แล้ว | เปิด http://127.0.0.1:8000/ ได้เลย (ใช้ตัวเดิม) หรือปิดหน้าต่างเดิมแล้วรันใหม่ หรือใช้ `-Port 8010` แล้วเปลี่ยน URL เป็น :8010 |
| สคริปต์ขึ้น `ERROR: -Reset refused` | มีเซิร์ฟเวอร์อื่นยังทำงาน | ปิดหน้าต่างเซิร์ฟเวอร์เดิม (Ctrl+C) แล้วรันใหม่ — สคริปต์ไม่ได้ลบอะไร |
| หน้าเว็บมี **แถบแดง “ขาดการเชื่อมต่อเซิร์ฟเวอร์”** + ที่นั่งเป็นลายเทาทั้งหมด | หน้าต่างเซิร์ฟเวอร์ถูกปิด/ล่ม | รันสคริปต์ใหม่ (ไม่ต้อง -Reset) — **หน้าเว็บเชื่อมต่อใหม่เองภายใน ≤15 วินาที** ไม่ต้องรีเฟรช (ทดสอบด้วยการ kill process จริง) · *ใช้เป็นจุดอธิบายได้:* “นี่คือ fail-safe — ไม่โชว์สีเขียวค้าง” |
