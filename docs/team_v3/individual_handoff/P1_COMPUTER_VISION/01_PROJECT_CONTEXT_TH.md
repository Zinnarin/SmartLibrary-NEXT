> ชุดเอกสารนี้อ่านจบในตัว: ไม่ต้องเข้าถึงบทสนทนา AI ของใคร — ไฟล์ 01–09 ในโฟลเดอร์นี้คือทุกอย่างที่ P1 ต้องรู้ (ฉบับเต็มของเอกสารร่วมอยู่ใน `docs/team_v3/individual_handoff/SHARED_V3/`)

## 1. Smart Library NEXT คืออะไร
ระบบแสดงสถานะที่นั่งห้องสมุด **เท่าที่หลักฐานยืนยันได้**: ถ้าไม่แน่ใจต้องบอกว่าไม่แน่ใจ (Unknown/Stale) ไม่ใช่เดาว่าว่าง ทีม 4 คนต่อยอดจากต้นแบบ V2 ที่รันได้จริงในเครื่อง (repo private `Zinnarin/SmartLibrary-NEXT`, tag `v2-demo-baseline`)

## 2. เป้าหมายร่วม V3 (ย่อ)
1) รับหลักฐานภาพจากภาพ/วิดีโอที่ **ได้รับอนุญาต** ← **งานของคุณ** · 2) backend ประเมินสถานะด้วย Seat State Engine · 3) เก็บ/เรียกข้อมูล · 4) แสดงข้อมูลที่น่าเชื่อถือบนเว็บนักศึกษา · 5) ค้นหา/แนะนำที่นั่ง · 6) ผู้ใช้รายงานสถานะผิด · 7) เจ้าหน้าที่ตรวจ · 8) รับมือข้อมูลเก่า/กล้องหาย/ข้อผิดพลาด · 9) แยกข้อมูลจำลองกับ CV จริง · 10) รันเป็นระบบเดียว
**ความแม่นยำบนที่นั่งจริงต้องวัด ไม่ใช่สมมติ**

## 3. ตำแหน่งของ P1 ในระบบ
```
ภาพ/วิดีโอที่ได้รับอนุญาต ──► [P1: detector + ROI + quality gate] ──evidence ต่อเฟรม──► POST /api/ingest/observations ──► [P2: classify + SeatStateEngine + DB]
                                   (cv/run_cv.py, cv/roi.py)            (สัญญา C1)                                     ──► เว็บนักศึกษา (P3) / Staff (P4)
```
**CV ส่ง "หลักฐาน" ไม่ใช่ "สถานะสุดท้าย"** — backend เป็นผู้ตัดสินสถานะด้วยกฎเดียวกับที่ใช้กับข้อมูลจำลอง

## 5. เพื่อนร่วมทีมและสิ่งที่คุณต้องการจากเขา
* **P2 (Backend):** เจ้าของ endpoint ingest และ engine ที่ `cv/run_cv.py` import; ต้องการจาก P2: PA-01 (`SL_CV_EVIDENCE_DIR`), PA-02 (422 เมื่อ timestamp เสีย), และถ้าทีมอนุมัติ PA-03 (ที่นั่ง CV จริงบนผัง)
* **P3 (Student frontend):** เจ้าของหน้า `CvLab.tsx` ที่อ่าน `latest_run.json` ของคุณ — ถ้าเปลี่ยน key ต้องแจ้ง
* **P4 (Staff/QA/Integration):** รวมงาน, รัน regression, อาจทำ adapter แปลง evidence file ของคุณเข้า API; ประสานเรื่องขออนุญาตฉากจริงกับอาจารย์

## 6. กติกาที่ห้ามละเมิด
ใช้เฉพาะภาพ/วิดีโอที่ได้รับอนุญาตเป็นลายลักษณ์อักษร · **ไม่ commit** วิดีโอ/เฟรม/ภาพบุคคล/weights · ไม่เชื่อม CCTV มหาวิทยาลัย · ห้ามอ้างความแม่นยำที่ไม่ได้วัด · ห้ามเรียกข้อมูลจำลองว่าผล CV · ห้ามเขียน DB ตรง · ห้ามแตะที่นั่ง `A01`–`C08`
