## เตรียมก่อนกดอัด (5 นาทีก่อน)
1. เปิด PowerShell ที่โฟลเดอร์โปรเจกต์ แล้วรัน
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\start_demo_windows.ps1 -Reset
   ```
2. เปิด 2 หน้าต่างเบราว์เซอร์วางคู่กัน: ซ้าย `http://127.0.0.1:8000/` (นักศึกษา), ขวา `http://127.0.0.1:8000/#/staff` → ใส่ PIN `staff-demo-2569`
3. แท็บที่ 3 (หน้าต่างขวา): `http://127.0.0.1:8000/#/lab` (Scenario Lab, ใช้ PIN เดียวกัน)
4. รอ ~10 วินาทีให้สถานะที่นั่งขึ้นครบ (ช่วงแรกเป็น “ไม่แน่ใจ” เพราะยังเก็บหลักฐานไม่ครบ — เป็นพฤติกรรมที่ตั้งใจ)
5. ตรวจว่ามุมบนซ้ายขึ้น **● Live (WebSocket)** และแถบส้ม **SIMULATION — NOT REAL CAMERA DATA**

## Fallback (ถ้าเดโมสดมีปัญหา)
* **เซิร์ฟเวอร์ไม่ขึ้น / พอร์ตชน:** รัน `scripts\start_demo_windows.ps1 -Port 8010` แล้วใช้ URL พอร์ต 8010
* **หน้าเว็บค้าง/WS หลุด:** มุมบนจะขึ้น “◐ Polling สำรอง” ข้อมูลยังอัปเดตทุก 3 วินาที — พูดต่อได้เลย (นี่คือ fallback ที่ออกแบบไว้)
* **สถานะเพี้ยนจากการซ้อม:** Scenario Lab → **รีเซ็ตฐานข้อมูลสาธิต** (หรือรันสคริปต์ด้วย `-Reset`) รอ 10 วินาที
* **เดโมใช้ไม่ได้เลย:** ใช้สไลด์ 6 (ภาพหน้าจอจริงจาก Playwright 4 ขั้น) และสไลด์ 5 (กล้องหลุด → STALE) พูดตามตารางข้างบนแทน และบอกตรง ๆ ว่ากำลังใช้ภาพที่ capture จากระบบที่รันจริงเมื่อคืน
* **ห้ามพูด:** “ติดตั้งกล้องแล้ว”, “แม่น X%”, “fine-tune แล้ว”, “Reserved คือมีคนจอง”, “real-time ทุกกรณี”, “ผ่าน PDPA แล้ว”

## ประโยคสำรองเมื่ออาจารย์ถาม
* *“ตัวเลข False Available เท่าไร?”* → “ยังไม่มีตัวเลขจริง เพราะยังไม่มี ground truth จากภาพที่ได้รับอนุญาต ตัวเลขใน Scenario Lab เป็นของข้อมูลจำลองที่เราเขียน truth เอง ใช้ทดสอบตรรกะเท่านั้น”
* *“YOLO รันจริงไหม?”* → “รันจริง (YOLO11n pretrained COCO บน CPU) กับภาพตัวอย่างที่มากับไลบรารี ผ่าน ROI 4 จุดและ state engine เดียวกัน แล้วส่งเข้า API เป็น source=cv แต่ไม่ใช่ภาพห้องสมุด”
* *“ถ้านักศึกษากดรายงานมั่ว?”* → “รายงานหนึ่งครั้งไม่เปลี่ยนสถานะ แค่ถอนจากคำแนะนำความเชื่อถือสูงและส่งให้เจ้าหน้าที่ตรวจ มี rate limit ต่อ session (3 ครั้ง/10 นาที, ซ้ำที่เดิมไม่ได้) และไม่เก็บตัวตน”
