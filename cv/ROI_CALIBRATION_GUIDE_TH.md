# คู่มือ calibrate ROI สำหรับวิดีโอทดสอบ 4–8 ที่นั่ง (ยังไม่ได้ทำกับห้องสมุดจริง)

> สถานะ: **DESIGNED_ONLY** สำหรับที่นั่งห้องสมุดจริง — ใช้เมื่อได้รับอนุญาตถ่ายวิดีโอ/ใช้ webcam ในฉากที่จัดขึ้นแล้วเท่านั้น
> ห้ามใช้กับกล้อง CCTV ของมหาวิทยาลัยหากยังไม่ได้รับอนุญาตเป็นลายลักษณ์อักษร

## 1. เตรียมฉาก (staged scene)
1. ขออนุญาตพื้นที่ + ผู้ที่จะปรากฏในภาพ (บันทึกชื่อผู้อนุญาต วันเวลา ในข้อความ `--consent`)
2. ตั้งกล้องมุมสูงเฉียงลง (ตามข้อเสนอ DOCX §3) ให้เห็นทั้งเบาะนั่งและพื้นโต๊ะของ 4–8 ที่นั่ง
3. ล็อกกล้องไม่ให้ขยับ (ถ้ากล้องเลื่อน ROI จะผิดทันที → ต้อง calibrate ใหม่)

## 2. วาด ROI บนภาพจากกล้องนั้น (พิกัด pixel ของภาพ ไม่ใช่พิกัดผัง SVG)
ต่อที่นั่งต้องมี 2 polygon:
* `seat_polygon` — บริเวณเบาะ/ช่วงสะโพกของคนที่ **นั่ง** (ใช้ตรวจ hip anchor = 65% จากบนของกล่อง person)
* `table_polygon` — พื้นโต๊ะหน้าที่นั่ง สำหรับสิ่งของ (backpack / handbag / suitcase / laptop / book)

ตัวอย่างไฟล์ (`my_roi.json`):
```json
{
  "source_image": "webcam-index-0",
  "image_size": [1280, 720],
  "seats": [
    {"seat_id": "LAB1", "seat_polygon": [[100,420],[260,420],[260,600],[100,600]],
     "table_polygon": [[90,300],[280,300],[280,410],[90,410]], "note": "ซ้ายสุด"}
  ]
}
```
ใช้ `seat_id` = `LAB1`..`LAB4` (มีใน DB แล้ว, camera `CV-LAB`) — ข้อมูลจะไม่ปนกับที่นั่งจำลองบนผังนักศึกษา

## 3. รัน
```powershell
.venv-cv\Scripts\python cv\run_cv.py webcam --index 0 --roi my_roi.json --frames 12 --interval 1 --post `
  --consent "ผู้ทดสอบ X ยินยอม, ฉากโต๊ะจัดขึ้นในห้อง Y วันที่ ..."
```
* ไม่บันทึกภาพเป็นค่าเริ่มต้น (`--save-annotated` เพื่อบันทึกภาพ annotate 1 ภาพ เฉพาะเมื่อมีความยินยอม)
* ผลถูกบันทึกที่ `evidence/cv/run_cam*.json` และดูสถานะ LAB seats ได้ที่หน้า CV Lab

## 4. สคริปต์ฉากทดสอบที่ควรถ่าย (map กับ failure cases ใน DOCX §10)
| ฉาก | คาดหวัง (ตาม design) |
|---|---|
| ที่นั่งว่าง มองเห็นชัด ≥ 6 วินาที | Available หลังผ่าน 4 เฟรม/5 วินาที |
| คนนั่งจริง | Occupied (P_SEATED) หลัง smoothing |
| คนเดินผ่าน / ยืนข้างโต๊ะ | ไม่เป็น Occupied ทันที; ถ้ายืนนาน → Unknown (P_NEAR_NOT_SEATED) |
| วางกระเป๋า/โน้ตบุ๊ก ไม่มีคน | Reserved = “พบสิ่งของ / อาจถูกจับจอง”, ไม่ปลดอัตโนมัติ |
| วางแก้วน้ำอย่างเดียว | ไม่เป็น Reserved (IGNORED_CUP) |
| ปิดไฟ / เอามือบังเลนส์ | dark/blur → Unknown |
| ถอดสาย webcam | no_frame → Unknown, กล้อง offline เมื่อเกิน heartbeat |

## 5. วัดผลอย่างซื่อตรง
ติดป้าย ground truth ด้วยมือรายเฟรม/รายช่วงเวลา แล้วคำนวณ **False Available rate**, confusion matrix ของสถานะ และ Unknown coverage —
ระบุจำนวนเฟรม เงื่อนไขแสง และเครื่องที่ใช้ทุกครั้ง ห้ามรวมข้อมูลจำลองเข้ากับตัวเลข CV จริง
